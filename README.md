# StockProject

이 저장소는 국내 주식 자동매매 데스크톱 앱 StockProject의 공개 소스 스냅샷입니다.

비공개 원본 저장소의 `main`이 변경되면 허용 목록에 포함된 소스만 자동으로 검증되어 이 저장소에 반영됩니다. 비공개 Git 이력, 로컬 자격증명, 계좌 정보, 로그·진단 파일, 내부 운영 문서와 에이전트 설정은 포함하지 않습니다.

## 포함 범위

- `src/stockbot/`: Python 거래·위험 관리·브로커 연동 소스
- `apps/electron-dashboard/`: Electron/React 운용 UI 소스
- `packaging/`, `tools/`: Windows 서비스와 설치 소스
- `tests/`: 회귀 테스트
- 안전한 예제 설정과 런타임 샘플 데이터

## 로컬 개발

Python 3.12 이상과 Node.js 22.12 이상이 필요합니다. 실제 자격증명은 커밋하지 말고 `.env.example`을 복사한 로컬 `.env`에만 저장하세요.

```powershell
py -3 -m pip install -e .
.\run-electron-dashboard.cmd
```

## 실거래 주의

이 소스는 수익을 보장하지 않습니다. 실거래는 실제 자금 손실 가능성이 있으며, 계좌·시장시간·미체결·손실 한도·주문 직전 검증을 포함한 모든 안전 게이트를 직접 확인해야 합니다. 공개 저장소에는 실제 API key, secret, token 또는 계좌번호를 등록하지 마세요.

이 저장소는 자동 생성되는 읽기 전용 미러입니다. 직접 수정한 내용은 다음 동기화에서 교체될 수 있습니다. 별도 라이선스가 명시되지 않은 파일에는 추가적인 사용·재배포 허가가 부여되지 않습니다.
